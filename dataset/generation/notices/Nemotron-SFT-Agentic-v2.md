## Dataset Description
The Nemotron-SFT-Agentic-v2 dataset is a collection of synthetic single-turn and multi-turn tool-use trajectories designed to strengthen models’ capabilities as interactive, tool-using agents. It targets tasks where the model must decompose user goals, decide when to call tools, and reason over tool outputs to complete tasks reliably and safely.


This dataset is ready for commercial use.

The dataset consolidates three internally curated components (described below as subsets) similar in structure and goals to the [nvidia/Nemotron-Agentic-v1](https://huggingface.co/datasets/nvidia/Nemotron-Agentic-v1) dataset.

### Tool calling
This subset has ~1.2M synthetic tool-use trajectories spanning single-turn, multi-turn, and multi-step tool use. Dialogues are seeded from existing tool sets and function-calling resources including [UltraTool](https://github.com/JoeYing1019/UltraTool), [ToolEyes](https://github.com/Junjie-Ye/ToolEyes), [AutoTools](https://github.com/mangopy/AutoTools), [API-Bank](https://github.com/AlibabaResearch/DAMO-ConvAI/tree/main/api-bank), and [glaiveai/glaive-function-calling-v2](https://huggingface.co/datasets/glaiveai/glaive-function-calling-v2). A subsample of trajectories from [Agent-Ark/Toucan-1.5M](https://huggingface.co/datasets/Agent-Ark/Toucan-1.5M) is included.  
Each trajectory is created by simulating three roles:
- **User**: provides a goal/task
- **Agent**: plans and interacts via tools
- **Tool environment**: returns tool outputs to be consumed by the agent

To improve quality, trajectories are **scored and filtered** by an LLM judge to remove inconsistent, incoherent, or incorrect tool usage. The tool-calling subset uses [DeepSeek-V3.2](https://huggingface.co/deepseek-ai/DeepSeek-V3.2) and [GLM-4.6](https://huggingface.co/zai-org/GLM-4.6) for simulation and judging.

### Search
The search subset contains 6,977 web-search trajectories intended to incentivize models to search the web to answer queries. Prompts are trivia-like questions created by querying [Wikidata](https://www.wikidata.org/wiki/Wikidata:Main_Page) entities and generating natural questions via an LLM. Trajectories are generated by querying a model equipped with a web-search tool. Most trajectories require ~10–30 search calls.

### Customer Service
This subset contains 278,880 multi-turn tool-use conversations across 838 domains (e.g., EdTech, IT support, Travel) in customer-service style scenarios, emphasizing expert agentic demonstrations (authentication, data lookup, booking/modifications, discounts, etc.). This subset is most suitable for supervised fine-tuning (SFT) to improve agentic capabilities in multi-turn conversational scenarios.

## Intended Usage
This dataset is intended for LLM engineers and research teams developing and training models for **agentic workflows** and **conversational tool use**, including:
- Supervised fine-tuning (SFT) for tool-use policy learning
- Data augmentation for tool routing / planning / decomposition
- Evaluation of end-to-end tool-using assistants
- Studying robustness of multi-role agent setups
- Training search-oriented agents (via `search_graph_walk`)
